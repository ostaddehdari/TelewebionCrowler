# تلوآرشیو جدید — استخراج مستقل تلوبیون (HTTP-first)

**پروژه قبلی `twcrawler` تغییر داده نمی‌شود.** این برنامه از PostgreSQL جدید به نام `newtwcrawler`، کاربر جدید `newtwcrawler`، پورت 18896 و مسیر `/newtwcrawler/` استفاده می‌کند.

## مرز ادعا

این طرح، **بازسازی استنباطی مدل داده از پاسخ‌های عمومی JSON** است؛ دسترسی یا اطلاعاتی درباره جداول خصوصی دیتابیس اصلی تلوبیون وجود ندارد. بنابراین نمی‌توان کامل‌بودن همه رکوردهای سایت اصلی را پیشاپیش تضمین کرد. هر پاسخ خام بدون حذف فیلد در `api_responses.payload` (JSONB) نگهداری می‌شود؛ فهرست موجودیت‌ها و روابط صرفاً شاخص قابل جست‌وجو هستند. داده‌های حاوی `content_token` در پایگاه‌داده خصوصی باقی می‌مانند و مقادیر توکن در رابط مدیریتی پوشانده می‌شوند. رسانه ویدئویی، فایل‌های HLS و DRM استخراج نمی‌شوند.

## پوشش APIها

- شبکه‌ها: کاتالوگ ۸۹ شناسه/descriptor از JSON ارسالی شما به‌عنوان بذر. اطلاعات برنامه‌های شبکه با `getProgramListByChannel` و صفحه‌بندی ۲۴تایی **دوباره از API جمع‌آوری می‌شود**؛ دیتابیس SQLite قبلی مصرف نمی‌شود.
- برنامه‌های عادی: `getProgramPage` و کلیپ‌ها: `getClipsByProgramID` در دسته‌های ۲۴تایی؛ نمونه‌های ارسالی `getProgram`، `queryProgram` و فیلد `is_clip` مبنای تفکیک هستند.
- برچسب‌ها: `getTagById` و `getEpisodesByTagId` با صفحه‌بندی.
- صفحات و فضاهای موضوعی: `v8/page/getPage` و `v8/space/getSpace`، شامل ردیف‌ها، کامپوننت‌ها، بنرها، اسلایدرها، مجموعه‌ها، و tagها.
- VOD: `get-content`، `get-serial`، `get-kids-serial`، `get-kids-serial-season`، `content-meta/get-content-meta` با صفحه‌بندی.
- فراداده بازیگران، سازندگان، پوسترهای معرفی، زبان‌ها، کشورها، امتیازها و موارد دیگر: به‌صورت کامل در `payload`، و شناسه‌های قابل شناسایی در `entities` و `links`.

**نکته پوشش:** `getProgramPage` در نمونه‌ها فقط بخشی از اپیزودهای عادی را برمی‌گرداند. API قطعی صفحه‌بندی *تمام قسمت‌های آرشیو یک برنامه عادی* هنوز مشخص نشده است. ابزار چیزی را بی‌دلیل «کامل» اعلام نمی‌کند. همچنین ساختار JSON دقیق `getClipsByProgramID` هنوز از نمونه پیوست تأیید نشده است؛ در حالت ناشناخته، رکورد خام نگهداری و Task در حالت `review` ثبت می‌شود.

## نصب Ubuntu 26.04

در **Git Bash ویندوز**، بعد از دانلود فایل ZIP:

```bash
scp -P 2233 ~/Downloads/Telewebion-NewCrawler-V1.zip root@5.61.28.187:/tmp/
ssh -p 2233 root@5.61.28.187
```

در **SSH سرور**:

```bash
mkdir -p /root/newtwcrawler-installer
unzip -o /tmp/Telewebion-NewCrawler-V1.zip -d /root/newtwcrawler-installer
cd /root/newtwcrawler-installer
bash -n deploy/install_ubuntu26.sh
bash deploy/install_ubuntu26.sh
```

برای مشاهده سایت رمز لازم نیست. فقط اتصال داخلی دیتابیس با یک رمز تصادفی و محرمانه برقرار می‌شود. نصب‌کننده:

1. یک دیتابیس و Role جدید PostgreSQL با رمز تصادفی ایجاد می‌کند.
2. یک محیط مجازی Python جدید می‌سازد و فقط وابستگی‌های HTTP را نصب می‌کند (بدون Chromium/Playwright).
3. ابزار استخراج را با بذر شبکه‌های جدید مقداردهی می‌کند؛ داده SQLite قبلی را کپی نمی‌کند.
4. `newtwcrawler-web` را روی `127.0.0.1:18896` بالا می‌آورد.
5. **فقط یک location تازه** به Virtual Host HTTPS فعلی Nginx اضافه می‌کند؛ نسخه و تنظیمات قبلی `twcrawler` تغییر نمی‌کنند. بکاپ Nginx تهیه می‌شود.
6. یک آزمایش محدود حداکثر ۴۰ درخواست HTTP را اجرا می‌کند. Timer خودکار **تا بررسی نتیجه آزمایش، غیرفعال** باقی می‌ماند.

### بررسی و فعال‌سازی جمع‌آوری ادامه‌دار

```bash
bash /root/newtwcrawler-installer/deploy/verify.sh
journalctl -u newtwcrawler-fetch -n 80 --no-pager
systemctl is-active twcrawler-web
```

اگر دریافت داده بدون خطا موفق بوده و پیام 403/429 یا `review` گسترده نداریم، فعال کنید:

```bash
systemctl enable --now newtwcrawler-fetch.timer
systemctl list-timers --all | grep newtwcrawler
```

کنترل:

```bash
systemctl stop newtwcrawler-fetch.timer
systemctl stop newtwcrawler-fetch.service
```

این توقف‌ها به سایت و دیتابیس قبلی دست نمی‌زنند.

## مسیرهای پروژه جدید

- ورودی عمومی: `https://5.61.28.187/newtwcrawler/`
- آرشیو: `https://5.61.28.187/newtwcrawler/`
- وضعیت استخراج: `https://5.61.28.187/newtwcrawler/dashboard`

گواهی SSL موجود روی IP توسط نصب‌کننده مجدداً صادر نمی‌شود. اگر گواهی فعلی خودامضاشده است، مرورگر هنوز به آن اعتماد نمی‌کند؛ برای مدیریت حساس از SSH tunnel یا گواهی معتبر استفاده کنید.

### سرعت و ترافیک

هر بار ۴۰ درخواست با فاصله دست‌کم ۱٫۵ ثانیه انجام می‌شود؛ پس از بررسی سلامت می‌توان ظرفیت را تنظیم کرد. **سرعت بالا نسبت به Chromium** ناشی از حذف اجرای مرورگر است، نه ارسال درخواست انبوه بدون محدودیت. در صورت HTTP 403/429، اجرا متوقف می‌شود و یک دوره وقفه یک‌ساعته ثبت می‌گردد.

## توسعه بعدی

برای رسیدن به پوشش کامل آرشیو برنامه‌های عادی، لینک Fetch/XHR بارگذاری قسمت‌های قدیمی هنگام اسکرول را نیز باید به فهرست APIها اضافه کنیم. افزودن endpoint جدید فقط در ماژول `newtwcrawler/crawler.py` انجام می‌شود؛ جداول خام نیازی به تغییر ندارند.


## انتشار عمومی بدون رمز عبور (V1.1)

این نسخه **هیچ فرم ورود یا رمز مدیریتی برای بازدیدکنندگان ندارد** و تمام مسیرهای خواندنی آرشیو، جزئیات، آمار و JSON سانسورشده از طریق `/newtwcrawler/` عمومی هستند.
توکن‌های API (مانند `content_token`) در دیتابیس جداگانه حفظ می‌شوند اما در نمای عمومی نمایش داده نمی‌شوند. هیچ عملیات تغییر وضعیت یا نوشتن دیتابیس از طریق HTTP وجود ندارد؛ استخراج فقط با سرویس systemd در سرور اجرا می‌شود.
`NEWTW_DATABASE_URL` دارای رمز داخلی PostgreSQL است؛ این رمز ورود به وب‌سایت نیست و باید در فایل امن `/etc/newtwcrawler/app.env` محافظت شود.

اگر نصب V1 در مرحله درخواست رمز متوقف شده است، بسته V1.1 را روی `/root/newtwcrawler-installer` استخراج و `bash deploy/install_ubuntu26.sh` را دوباره اجرا کنید. نصب، فقط پایگاه‌داده و Nginx مستقل newtwcrawler را مدیریت می‌کند و به `/twcrawler/` قبلی دست نمی‌زند.
