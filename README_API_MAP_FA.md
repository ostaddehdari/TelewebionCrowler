# نقشه APIهای تلوبیون (مرحله HTTP-first)

بر اساس درخواست‌های Fetch/XHR ارسال‌شده توسط کاربر در اکتبر ۲۰۲۶؛ پاسخ JSON زنده هنوز در این محیط مشاهده نشده و ساختار فیلدها باید با `scripts/probe_kandoo_endpoints.py` تأیید شود.

| بخش | مسیر | صفحه‌بندی | وضعیت |
|---|---|---|---|
| جزئیات برنامه | `/kandoo/program/getProgramPage/?ProgramID=0x10000569` | هنوز مشخص نیست | درخواست واقعی مشاهده‌شده در مرورگر؛ پوشش قسمت/کلیپ نیازمند بررسی خروجی |
| فهرست برنامه‌های شبکه | `/kandoo/channel/getProgramListByChannel/?Descriptor=abadan&First=24&Offset=24` | `First=24`, `Offset=0,24,48,...` | مسیر واقعی؛ تشخیص کلید فهرست از JSON |
| سریال کودک | `/kandoo/vod/content/get-kids-serial?content_id=0xc208c07&first=10&offset=10` | `first=10`, `offset=0,10,20,...` | مسیر واقعی؛ تشخیص نوع آیتم از JSON |
| فصل‌های کودک | `/kandoo/vod/content/get-kids-serial-season?content_id=0xc208c07&season=1&first=10&offset=0` | فصل+offset | از قبل توسط آزمون کاربر پاسخ ۲۰۰ و ۱۰ قسمت دریافت شده است |

## پوشش نیازمند بررسی بیشتر

- آرشیو قسمت‌های برنامه‌های معمولی (نمونه `/program/0x10000569/archive`)؛ آیا `getProgramPage` کل آرشیو را برمی‌گرداند یا endpoint جدا دارد؟
- کلیپ‌های برنامه‌های معمولی؛ ممکن است endpoint یا پارامتر جدا داشته باشند.
- فیلم/محصول `/product/0xc207ceb`؛ باید Fetch/XHR مربوط به جزئیات، قسمت‌ها و کلیپ‌ها بررسی شود.
- شبکه‌ها/دسته‌های مجازی، اگر `getProgramListByChannel` با Descriptor آن‌ها کار نکند.

برای بررسی یک مورد، در DevTools > Network > Fetch/XHR، درخواست صفحه اول و صفحه دوم و **URL بدون توکن نشست** را ثبت کنید. نام فیلدهای JSON و تعداد آیتم هر صفحه نیز لازم است. از کپی شناسه‌های نشست یا Authorization خودداری کنید.

## الزامات حلقه استخراج

- اندازه صفحه هر API را با همان API تعیین کنید (فرض نکنید همه ۲۰ هستند).
- شروع از offset صفر و افزایش به اندازه `first` یا `First`.
- خاتمه هنگام پایان مستند‌شده صفحه‌بندی، پاسخ خالی، یا تکرار صفحه/شناسه‌ها؛ فقط بر مبنای `len < first` با احتیاط.
- رعایت 429/403، وقفه و محدودیت تعداد درخواست؛ عدم تلاش برای دورزدن.
- نگهداری شناسه‌های ثابت و upsert در PostgreSQL؛ برچسب `done` فقط بعد از اثبات پوشش کافی.
- فعلاً `twcrawler-worker` مرورگرمحور را خاموش نگه دارید.
