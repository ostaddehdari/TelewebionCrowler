# افزودنی SQLite + Flask + استخراج قسمت و کلیپ تلوبیون

این بسته شامل کرولر جامع V4 و افزودنی استخراج فرزندان هر برنامه است. **برنامه‌های اصلی** در `programs` و **قسمت‌ها/کلیپ‌ها** در جدول جداگانه `media_items` قرار می‌گیرند. جدول `program_channels` ارتباط چندبه‌چند برنامه با شبکه‌ها را ثبت می‌کند.

## نصب/اجرای ویندوز

1. کل پوشه `Telewebion_Episode_Catalog_V1` را از ZIP استخراج کنید.
2. اگر قبلاً با V4 همه شبکه‌ها را استخراج کرده‌اید، **تمام پوشه خروجی `output` از V4 قبلی را در پوشه همین پروژه کپی کنید** (به‌ویژه `all_programs.json` و `by_network.json`). لازم نیست ده‌ها هزار عنوان را از نو بگیرید.
3. `run_episode_crawler.bat` را اجرا کنید؛ این فایل `all_programs.html` قبلی را نیز به‌صورت خودکار پشتیبان‌گیری و دو دکمه جدید را به هر کارت اضافه می‌کند؛ مرورگر Chrome یا Edge نصب‌شده استفاده می‌شود و نصب Chromium لازم نیست.
4. سایت مدیریت روی `http://127.0.0.1:18895/` و گزارش لحظه‌ای روی `http://127.0.0.1:18895/dashboard` باز می‌شود.
5. اگر ابتدا می‌خواهید فقط ۵ برنامه را بررسی کنید، `RUN_PILOT_5.bat` را اجرا کنید و سپس `dashboard.py` را باز کنید. با `py -3 episode_worker.py --program program:0x16b69aa2 --headed` فقط یک برنامه را آزمایش کنید.

### دستورهای اصلی

```powershell
py -3 -m pip install -r requirements.txt
py -3 import_catalog.py
py -3 episode_worker.py --workers 2 --limit 5 --headed
py -3 dashboard.py
```

پس از آزمون، برای همه عنوان‌های هنوز بررسی‌نشده:

```powershell
py -3 episode_worker.py --workers 2
```

برای یک شبکه خاص:

```powershell
py -3 episode_worker.py --slug irinn --workers 1
```

برای سریال‌های کودک:

```powershell
py -3 episode_worker.py --kind kids --workers 1 --max-api-pages 300
```

تکرار کرول امن است؛ کلیدهای یکتای آیتم‌ها مانع تکرار می‌شوند. موارد `done` مجدداً اجرا نمی‌شوند. موارد خطادار تا `--max-attempts 3` بار مجدداً تلاش می‌شوند. در صورت نیاز به تکرار دستی برای موارد `partial` از `--retry-partial` استفاده کنید.

### ذخیره و ساختار

- `data/telewebion.sqlite3`: پایگاه داده اصلی، شامل `channels`, `programs`, `program_channels`, `media_items`, `jobs`, `events`.
- `output/all_programs.html`: HTML قبلی V4 با دو دکمه فهرست قسمت‌ها/کلیپ‌ها؛ `patch_existing_html.py` بدون تغییر داده جاسازی‌شده آن را اصلاح می‌کند. **اگر فقط پوشه output را کپی کرده‌اید، `run.py build` را اجرا نکنید** زیرا برای آن به `data/raw` نیز نیاز است.
- `http://127.0.0.1:18895/`: گالری چهارستونه Flask با شمارش رکورد واقعی.
- `http://127.0.0.1:18895/dashboard`: رویدادهای استخراج و گزارش وضعیت شبکه‌ها.
- `output/episodes_export/all_episodes.json`, `all_clips.json`، `programs_with_counts.json`، `program_details.json` و `by_program/*.json`: خروجی JSON مستقل از بانک، پس از اجرای `py -3 export_episode_json.py`.

### روش استخراج

- `/program/{id}/archive`: پیمایش کارت‌ها، تشخیص قسمت و شناسایی بخش `data-row-type="programClip"` به عنوان کلیپ، همراه با پاسخ‌های JSON مشاهده‌شده در مرورگر.
- `/program/{id}`: محتوای تکمیلی صفحه اصلی برنامه.
- `/product/{id}`: مشاهده صفحه محصول و کارت‌های فرزند در صورت وجود.
- `/kids/{id}`: پردازش API رسمی مشاهده‌شده `get-kids-serial-season` با `content_id,season,first,offset`. فصل‌ها و شماره قسمت‌ها به صورت رابطه‌ای ذخیره می‌شوند. اگر صفحه نشان ندهد که شناسه `serial_parts.content_id` چه لینک عمومی دارد، لینک مستقیم ساخته نمی‌شود.
- نام قسمت، شناسه، شماره فصل/قسمت، عکس (در صورت دسترس)، توضیح، زمان/تاریخ پخش (در صورت حضور) و JSON خام در بانک ثبت می‌شود.

**دقت:** API کودک با نمونه JSON ارسالی آزمون شده است؛ ساختار APIهای دیگر به‌طور قطعی تأیید نشده و crawler با تکیه بر DOM و پاسخ JSON مشاهده‌شده در Chrome استخراج می‌کند. عبارت `done` یعنی تلاش پیمایش با قوانین فعلی بدون خطا تمام شده، نه تضمین بی‌نقص بودن کل آرشیو سایت. گزارش `partial` و `failed` را بررسی کنید.

**امنیت/حق نشر:** این کرولر فقط داده‌های متنی و URL تصاویر را ذخیره می‌کند؛ فایل ویدئو، آدرس‌های رمزدار، محتوای نیازمند مجوز یا DRM را دانلود نمی‌کند. استخراج چندده‌هزار برنامه زمان/منابع قابل‌توجهی می‌خواهد؛ سرعت را کم نگه دارید.

### توضیح دیتابیس و بازگردانی

رکورد `program:0x16b69aa2` مستقل از `program:0x16b69aa2` در چند شبکه تکرار نمی‌شود، اما هر دو عضویت شبکه در `program_channels` حفظ خواهد شد. رکوردهای اپیزود فقط در `media_items` قرار دارند و هیچ‌گاه به جدول `programs` افزوده نمی‌شوند. برای پشتیبان‌گیری در زمانی که برنامه کار نمی‌کند، فایل SQLite را کپی کنید؛ وقتی برنامه اجراست، از API آنلاین SQLite backup استفاده کنید یا هر سه فایل database, `-wal` و `-shm` را با رعایت سازگاری ذخیره کنید.
